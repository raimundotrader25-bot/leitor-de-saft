# Leitor de SAF-T

Abra **https://raimundotrader25-bot.github.io/leitor-de-saft/** e arraste o ficheiro SAF-T (.xml) para a página.

O ficheiro é lido só no seu navegador e não é enviado para lado nenhum. Funciona com SAF-T de Angola (kwanzas) e de Portugal (euros).

Mostra alertas (NIF, contas de IVA, isenções, numeração, notas de crédito), vendas com e sem IVA, notas de crédito fatura a fatura, faturas por receber, vendas mês a mês, maiores clientes e produtos, e a lista completa de documentos.
